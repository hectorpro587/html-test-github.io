# HtmlTest

HtmlTest es una página web que demuestra, con ejemplos reales, lo que se puede lograr usando solo HTML, CSS y JavaScript, sin frameworks ni dependencias externas. Su objetivo es mostrar de forma práctica que el navegador es una plataforma capaz de renderizar gráficos en 3D, simulaciones interactivas y interfaces visuales modernas.

## Objetivo

Cada ejemplo enlazado desde la página principal es un archivo HTML independiente que explora una capacidad distinta de la web:

- **BouncingBall**: una simulación inspirada en la demo Boing Ball de la Commodore Amiga, que demuestra que HTML puede renderizar objetos en 3D.
- **ShipRadar**: una simulación interactiva de radar de barco que recrea el barrido circular de una pantalla náutica.

La página principal sirve como punto de entrada: presenta los ejemplos, enlaza al perfil de GitHub del autor y utiliza efectos de vidrio esmerilado, animaciones y brillos interactivos inspirados en iOS 26 para demostrar lo que CSS y JavaScript pueden hacer en la interfaz.

## Uso

Abre `index.html` en cualquier navegador moderno. También puedes publicar el proyecto con GitHub Pages para verlo en línea.
